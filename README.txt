RIAD – GEBÄUDETECHNIKPLANER SANITÄR EFZ 2026–2030
LERN-APP – Version 0.1

START:
1. ZIP vollständig entpacken.
2. Doppelklick auf START_APP.cmd.
3. Die App öffnet sich im Browser.
4. Das schwarze Fenster offen lassen, solange die App läuft.

Alternativ kann index.html direkt geöffnet werden. Der lokale Server ist aber
zuverlässiger für PDF-Anzeige und eingebettete Videos.

ENTHALTEN:
- Mathematik-Schuldossier inkl. vorhandener Lösungsseiten
- Grundlagen Technisches Zeichnen
- Planbearbeitung PB1-a
- Planbearbeitung PB1-b/c/d/e
- Projekt «Unser Haus»
- offizielle Ausbildungsgrundlagen 2025–2030 / Archiv
- QR-Video zur Dreitafel-/Normalprojektion
- interaktive Aufgaben, Richtig/Falsch und Lösungsbutton
- lokaler Lernfortschritt via Browser-Speicher

HINWEIS:
Die App ist als erste funktionsfähige Version angelegt. Weitere Schuldossiers,
Normen, Lehrmittel und neu erkannte QR-Videos können später ohne Neuaufbau der
Grundstruktur ergänzt werden.
